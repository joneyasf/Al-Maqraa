# لوجه الله — المقرأة الليلية

تطبيق المقرأة الليلية للقرآن الكريم، صدقة جارية.
مجاني، مفتوح المصدر، بدون إعلانات، بدون حسابات.

> **صلِّ على النبيّ وادعُ لوالدي بالرحمة والمغفرة**

## ما هو التطبيق؟

كل ليلة الساعة **10:30 – 11:00 م** بتوقيت القاهرة، يجتمع أعضاء المقرأة لقراءة القرآن.
الشيخ يقود الجلسة بالفيديو، وباقي الأعضاء صوت فقط، وكل واحد يعرف دوره إمتى،
والصفحة بتتقلب عند الكل مع بعض، والختمة بتتقدم جزء جزء.

## المميزات

- **الشريط الافتتاحي**: الجملة أعلاه تظهر أول ما يفتح التطبيق، وتفضل مثبّتة أعلى الصفحة الرئيسية.
- **العد التنازلي** لموعد المقرأة (10:30 م)، ويتحدث كل ثانية.
- **غرفة صوتية Jitsi** داخل التطبيق (غرفة ثابتة: `maqraa-liwajhullah-daily` على `meet.jit.si`):
  الصوت مفتوح افتراضيًا، والفيديو مغلق افتراضيًا ما عدا الشيخ، ومن يطلب منه الشيخ.
  وإذا تعذّر الاتصال من الـ SDK، يفتح التطبيق الغرفة في المتصفح كبديل.
- **المصحف**: 604 صفحات بالرسم العثماني، بحث بالسورة والجزء والصفحة،
  إشارات مرجعية، حفظ آخر صفحة، تكبير الخط.
  الصفحات 1 و601–604 مضمّنة أوفلاين، وباقي الصفحات تُحمَّل أول مرة من الإنترنت ثم تُحفظ.
- **الختمة**: 30 جزءًا، كل جزء يُعلَّم عند إتمامه، وشريط تقدم ذهبي،
  وختمات مكتملة تُهدى لوالد صاحب التطبيق رحمه الله،
  وزر "ابدأ ختمة جديدة واهدها لميت".
- **الأعضاء والحضور**: قائمة الأعضاء، من يقرأ الآن، من التالي،
  عدد ليالي الحضور المتتالية، وعدد الصفحات.
- **دعاء لوالدي** بعد كل جلسة، في الرئيسية وعند المغادرة.
- **تذكير** قبل المقرأة بـ 15 دقيقة (10:15 م).

## الأرقام — مهم جدًا

**الافتراضي في كل مكان في التطبيق هو الأرقام المشرقية ٠١٢٣٤٥٦٧٨٩**:
أرقام الآيات، أرقام الصفحات، الأجزاء، العد التنازلي، الساعات، النسب.
هذا مطبّق في الرئيسية والعد التنازلي والمصحف والختمة والأعضاء والإعدادات،
والقيمة الافتراضية في `AppState` هي `easternNumerals = true`
(وفي التخزين `prefs.getBool('easternNumerals') ?? true`).

الأرقام الإنجليزية 123 موجودة كخيار ثانوي فقط في **الإعدادات ← الأرقام**،
لمن يريدها، ولا تظهر إلا إذا اختارها المستخدم بنفسه.

## التقنية

- Flutter 3.32 + Dart، Material 3، عربي RTL بالكامل.
- `jitsi_meet_flutter_sdk: ^11.6.0` للغرفة الصوتية.
- `shared_preferences` للحفظ المحلي، `flutter_local_notifications` للتذكير.
- بيانات القرآن: أسماء السور الـ 114 وعدد آياتها وصفحاتها وبدايات الأجزاء الثلاثين
  (المصحف المدني) في `lib/data/quran_data.dart`،
  ونص الصفحات من AlQuran Cloud مع تخزين مؤقت.
- ملفات `lib/widgets/` الستة الأولى كتبها Claude كما هي دون تعديل،
  وباقي المشروع مكمّل عليها.

## بناء الـ APK من GitHub Actions

1. ارفع المشروع على GitHub في مستودع `joneyasf/maqraa` فرع `main`.
2. افتح تبويب **Actions** في المستودع — سيعمل البناء تلقائيًا عند كل Push.
3. بعد نجاح البناء، افتح تشغيل **Build APK** ثم **Artifacts ← app-debug** وحمّل ملف `app-debug.apk`.
4. على الموبايل: ثبّت الملف (اسمح بالتثبيت من مصادر غير معروفة لهذا الملف فقط)،
   ثم امنح التطبيق إذن **الميكروفون** و**الكاميرا** عند أول دخول للمقرأة.

للبناء محليًا:

```bash
python3 tools/generate_icons.py
flutter pub get
flutter build apk --debug
```

ملاحظة: أيقونات `mipmap/ic_launcher.png` لا تُرفع مع الملفات النصية،
بل يولّدها سكربت `tools/generate_icons.py` تلقائيًا قبل كل بناء
(في GitHub Actions وفي البناء المحلي).
